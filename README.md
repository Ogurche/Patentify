Репозиторий хакатона ЛЦТ 2024

Сервис анализа патентователей
Задача: Разработать веб-сервис, который позволит загружать и парсить первичные данные о патентах
, а также формировать на основе этих данных перечни патентов, размеченных по авторам и правообладателям.

Ключевой частью сервиса должен стать алгоритм, который позволит разметить патенты по ИНН юрлиц и индивидуальных предпринимателей, а также ID физлиц.
